# monoherdr

Tui's custom [Herdr](https://herdr.dev) config.

- `config.toml`: symlinked to `~/.config/herdr/config.toml`
- `./install.sh`: back up the existing config, create the symlink, reload the server

Docs: [Configuration](https://herdr.dev/docs/configuration/) · [Config reference](https://herdr.dev/docs/config-reference/)
